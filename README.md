# 📝 To-Do List

Une application simple et minimaliste pour gérer ses tâches quotidiennes, développée en JavaScript natif.

## ✨ Fonctionnalités

* Ajouter une tâche.
* Cocher une tâche terminée.
* Supprimer une tâche.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🚀 Comment lancer le projet ?

1. Téléchargez ou clonez les fichiers du projet.
2. Double-cliquez sur le fichier `index.html` pour l'ouvrir dans votre navigateur.
